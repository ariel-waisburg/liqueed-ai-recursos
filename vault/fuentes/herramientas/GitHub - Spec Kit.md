## En una línea
Toolkit open source de GitHub para trabajar con agentes de código siguiendo Spec-Driven Development.

## Ideas clave
- Les da a los agentes de código procesos estructurados, plantillas reutilizables y resultados documentados.
- Flujo central: escribir una 'constitución', especificar, planificar, partir en tareas, implementar y converger; cada paso es un comando del agente.
- Extensiones para corregir bugs (con veredicto verificado, parcial o fallido) y para evaluar ideas (seguir, aclarar o matar).
- Se adapta con presets, extensiones y workflows, y funciona con varios agentes de código.
